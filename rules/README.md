# Opencode Rules

Regole always-on che si applicano a tutti gli agenti.

## Esemple

- **Security**: non commitare credenziali
- **Workflow**: usare branch separati, mai pushare su main
- **Code style**: preferire semplicità su complessità
- **Communication**: spiegare il perché, non solo il cosa
